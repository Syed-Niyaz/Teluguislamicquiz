# ☪️ ఇస్లామిక్ తెలుగు క్విజ్ (Islamic Telugu Quiz)

ఆధునిక **React.js** తో రూపొందించబడిన ఇస్లామిక్ నాలెడ్జ్ క్విజ్ వెబ్ అప్లికేషన్. రోజువారీ క్విజ్ (10 ప్రశ్నలు / 3 నిమిషాలు), WhatsApp ఛానెల్ ద్వారా ఫలితాల ప్రకటన, అడ్మిన్-మాత్రమే లీడర్‌బోర్డ్ మరియు **Google Sheets (Google Apps Script)** అనుసంధానం ఉన్నాయి.

---

## 🌟 ముఖ్య విశేషాలు (Key Features)

1. **రోజువారీ క్విజ్**: ప్రతి రోజు 10 ప్రశ్నలు, 3 నిమిషాల కౌంట్‌డౌన్ టైమర్.
2. **ఫలితాలు WhatsApp లో**: రోజువారీ/వీక్లీ క్విజ్ సబ్మిట్ చేసిన తర్వాత స్కోర్ వెంటనే కనిపించదు — "ఫలితాలు & లీడర్‌బోర్డ్ WhatsApp ఛానెల్ లో చూడండి" అని చూపిస్తుంది. జవాబుల సమీక్ష (మీ ఎంపిక + వివరణలు) మాత్రం అందుబాటులో ఉంటుంది. గత క్విజ్ ప్రాక్టీస్ లో మాత్రమే స్కోర్ వెంటనే కనిపిస్తుంది.
3. **అడ్మిన్-మాత్రమే లీడర్‌బోర్డ్**: లీడర్‌బోర్డ్ తెరవడానికి అడ్మిన్ పాస్‌వర్డ్ అవసరం.
4. **Google Sheets అనుసంధానం**: ప్రతి ఫలితం తేదీ, సమయం, పేరు, ప్రాంతం, వృత్తి, స్కోర్ మరియు తీసుకున్న సమయంతో పాటు `quiz` ట్యాబ్‌లో నమోదు అవుతుంది.
5. **మొబైల్ ఫ్రెండ్లీ UI**: ప్రశాంతమైన ఇస్లామిక్ రంగులు, హెడర్ మెనూ, మునుపటి క్విజ్‌ల పేజీ, WhatsApp ఛానల్ లింక్.

> 🎖️ **మీ ప్రోగ్రెస్ & బ్యాడ్జ్ లు**: హోమ్ పేజీలోని ప్రత్యేక బటన్ ద్వారా మీ పేరు, పాయింట్లు, వరుస రోజులు, ఇస్లామిక్ అభినందనలు మరియు 10 అందమైన బ్యాడ్జ్ లు చూడండి. బ్యాడ్జ్ లు నిజమైన షరతులతో అన్ లాక్ అవుతాయి, అన్ లాక్ తేదీ ఈ బ్రౌజర్ లో భద్రపరచబడుతుంది.

### 🎨 బ్యాడ్జ్ ఐకాన్ ఫైల్స్ (Adding your own badge icons)

మీ స్వంత ఐకాన్ ఫైల్స్ `src/assets/badges/` లో పెట్టాలి. ఫైల్ పేరు బ్యాడ్జ్ id లేదా iconKey తో సరిపోవాలి — ఉదాహరణకు `niyyat.svg`, `sabr.png`, `crown.webp`. (`badge-` / `icon-` ప్రిఫిక్స్ కూడా అనుమతించబడుతుంది.) `.svg`, `.png`, `.webp`, `.jpg`, `.jpeg` ఫార్మాట్లు పని చేస్తాయి. ఫైల్ లేనప్పుడు అంతర్నిర్మిత లైన్ ఐకాన్ కనిపిస్తుంది. వివరాల కోసం `src/assets/badges/README.txt` చూడండి.

## ▲ Vercel లో Deploy చేయడం (Deploy on Vercel)

1. `node_modules` మరియు `dist` ఫోల్డర్లను GitHub కి పంపకూడదు — `.gitignore` లో అవి ఇప్పటికే ఉన్నాయి. (గతంలో అప్‌లోడ్ అయి ఉంటే: `git rm -r --cached node_modules dist` → commit → push.)
2. Vercel → **Add New → Project** → మీ GitHub రిపోజిటరీ ఎంచుకోండి.
3. Framework Preset: **Vite** (ఆటోమేటిక్‌గా వస్తుంది)
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Install Command: `npm install`
4. **Deploy** నొక్కండి. `prebuild` స్క్రిప్ట్ ఆటోమేటిక్‌గా రన్ అవుతుంది; అది విఫలమైనా బిల్డ్ ఆగదు (warning మాత్రమే).
5. ప్రశ్నలు మార్చిన ప్రతిసారి GitHub కి push చేస్తే Vercel తనంతట తానే మళ్లీ deploy చేస్తుంది.

> ⚠️ `node_modules` ను GitHub కి commit చేయడం వల్ల Vercel (Linux) బిల్డ్ విఫలమవుతుంది — `Cannot find module @rollup/rollup-linux-x64-gnu` వంటి ఎర్రర్ వస్తుంది. పై `.gitignore` పద్ధతి దాన్ని సరిచేస్తుంది.

## 📊 Google Sheets అనుసంధానం (Google Apps Script Setup)

ఈ ప్రాజెక్ట్‌లోని `google-apps-script.js` ఫైల్‌లో సిద్ధంగా ఉన్న కోడ్ ఉంది:

1. మీ Google Drive లో **Google Sheet** తెరవండి.
2. మెనూ నుండి **Extensions > Apps Script** క్లిక్ చేయండి.
3. `google-apps-script.js` ఫైల్‌లోని కోడ్ మొత్తాన్ని కాపీ చేసి, Apps Script ఎడిటర్‌లో పేస్ట్ చేయండి.
4. సేవ్ (💾) చేయండి.
5. **Deploy > New deployment** → **Web app** ఎంచుకోండి:
   - **Execute as**: `Me`
   - **Who has access**: `Anyone`
6. **Deploy** నొక్కి అనుమతులు (Authorize) ఇవ్వండి.
7. వచ్చిన **Web app URL** ను `src/services/sheetService.js` లోని `DEFAULT_SCRIPT_URL` కి సెట్ చేయండి (లేదా యాప్‌లో సేవ్ చేయండి).
8. మీ Google Sheet లో **`quiz`** అనే ట్యాబ్ ఉండేలా చూసుకోండి (లేకపోతే స్క్రిప్ట్ స్వయంగా సృష్టిస్తుంది).

### 🔐 అడ్మిన్ పాస్‌వర్డ్

- లీడర్‌బోర్డ్ పాస్‌వర్డ్: `Syed2002@`
- ఇది `src/services/sheetService.js` (`ADMIN_PASSWORD`) మరియు `google-apps-script.js` (`ADMIN_PASSWORD`) రెండింటిలోనూ సమానంగా ఉండాలి.
- పాస్‌వర్డ్ మార్చాలంటే **రెండు ఫైల్స్**లో మార్చి, Apps Script ను **కొత్త వెర్షన్‌గా మళ్లీ Deploy** చేయండి.

### 🔄 స్క్రిప్ట్ అప్‌డేట్ చేసినప్పుడు

Apps Script లో కోడ్ మార్చిన ప్రతిసారీ **Deploy > Manage deployments > Edit > Version: New version > Deploy** చేయాలి. లేకపోతే పాత కోడ్ మాత్రమే రన్ అవుతుంది.

> **పేస్ట్ చేసేటప్పుడు:** ముందు `Code.gs` లోని పాత కోడ్ మొత్తాన్ని (Ctrl+A → Delete) తీసేసి, పూర్తి కోడ్ పేస్ట్ చేయండి. ఫైల్ చివరి లైన్ ఒకే `}` ఉండాలి (మొత్తం **304 లైన్లు**). సగం పేస్ట్ అయితే `Syntax error: Unexpected end of input` వస్తుంది. బ్యాకప్ కాపీ: `backup/google-apps-script-quiz-leaderboard.js`.

## ➕ కొత్త ప్రశ్నలు ఎలా జోడించాలి (How to Add Daily Questions)

### ఎలా పని చేస్తుంది (How it works)

- అన్ని ప్రశ్నలు `src/data/questions.js` లోని `QUIZ_QUESTIONS` జాబితాలో ఉంటాయి.
- ప్రతి రోజు ఆ జాబితా నుండి **తేదీ ఆధారంగా 10 ప్రశ్నలు** ఆటోమేటిక్‌గా ఎంపిక అవుతాయి (`seededShuffle(QUIZ_QUESTIONS, dateKey).slice(0, 10)`).
- అంటే ప్రశ్నలు జోడిస్తే చాలు — ప్రతి రోజు కొత్త 10 ప్రశ్నలు వస్తాయి. రోజువారీ క్విజ్‌ను మీరు ప్రత్యేకంగా సెట్ చేయాల్సిన అవసరం లేదు.

### దశలు (Steps)

1. `src/data/questions.js` తెరవండి.
2. `QUIZ_QUESTIONS` జాబితా చివరలో (చివరి `}` తర్వాత కామా పెట్టి) కొత్త ప్రశ్నను ఇలా జోడించండి:

```js
  {
    id: 21,                       // ఇప్పటివరకు ఉన్న చివరి id + 1
    question: "మీ ప్రశ్న ఇక్కడ రాయండి?",
    options: ["ఆప్షన్ 1", "ఆప్షన్ 2", "ఆప్షన్ 3", "ఆప్షన్ 4"],
    correctIndex: 1,              // సరైన సమాధానం స్థానం: 0, 1, 2 లేదా 3 (0 = మొదటి ఆప్షన్)
    explanation: "సరైన సమాధానానికి వివరణ."
  },
```

3. `npm run build` రన్ చేయండి.
4. `dist` ఫోల్డర్‌ను మీ హోస్టింగ్ (Netlify / Vercel / GitHub Pages) లో మళ్లీ అప్‌లోడ్ చేయండి.

### ముఖ్య గమనికలు (Important notes)

- **`correctIndex` 0 నుండి మొదలవుతుంది** — `0` = మొదటి ఆప్షన్, `1` = రెండవ ఆప్షన్, `2` = మూడవది, `3` = నాల్గవది.
- ప్రశ్నలు ఎక్కువగా ఉంటే (ఉదా: 50+) ప్రతి రోజు పునరావృత్తి తక్కువగా ఉంటుంది. 20 ప్రశ్నలతో ప్రతి 2 రోజులకు సెట్ మారుతుంది.
- ప్రశ్నలు కోడ్‌లోనే ఉంటాయి — ప్రశ్నలు జోడించిన ప్రతిసారి **`npm run build` + `dist` upload** చేయాలి. Google Sheet నుండి ప్రశ్నలు తీసుకునే ఫీచర్ తీసివేయబడింది.
- Google Sheet లో **`quiz`** ట్యాబ్ మాత్రమే ఉంటుంది (ఫలితాలు + లీడర్‌బోర్డ్). వేరే `questions` షీట్ అవసరం లేదు.

### 🕘 పాత క్విజ్ ప్రశ్నలు ఎప్పుడూ మారవు (Old Quizzes Stay the Same)

- ప్రతి రోజు 10 ప్రశ్నలు మొదటి **`npm run build`** సమయంలో `src/data/dailySnapshots.json` లో ఫ్రీజ్ (సేవ్) అవుతాయి.
- తర్వాత ప్రశ్నలను మార్చినా, కొత్తవి జోడించినా — **పాత తేదీల ప్రశ్నలు మారవు**. ఆ రోజు ఆడిన ప్రశ్నలే మళ్లీ కనిపిస్తాయి.
- `npm run build` చేసినప్పుడు ఫ్రీజ్ కాని కొత్త తేదీలు మాత్రమే జోడవుతాయి; ఇప్పటికే ఉన్న తేదీలు ఎప్పుడూ ఓవర్‌రైట్ అవవు.
- **ఈరోజు** ప్రశ్నలు మార్చాలంటే (ఉదా: తప్పు సవరించాలంటే): `npm run quiz:refresh-today` తర్వాత `npm run build`.

### 👀 పాత ప్రశ్నలు ఎలా చూడాలి (How to Check Previous Questions)

హెడర్ ☰ → **మునుపటి క్విజ్‌లు** → తేదీ పక్కన **ప్రశ్నలు చూడండి** నొక్కండి. ఆ రోజు 10 ప్రశ్నలు, అన్ని ఆప్షన్లు, సరైన జవాబు (✓) మరియు వివరణ కనిపిస్తాయి. **Play** నొక్కితే ఆ రోజు క్విజ్‌ని మళ్లీ ప్రాక్టీస్ చేయవచ్చు.
